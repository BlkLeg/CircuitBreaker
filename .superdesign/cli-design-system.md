# Circuit Breaker terminal design
This target is a terminal CLI, represented by a browser mockup for review. It has no app navigation, dock, web logo slot, cards, buttons, or app shell. Existing ASCII cb_logo from install.sh:669:724 is its exact identity artwork. Preserve every artwork character and line position; interpret interpolated shell color variables as ANSI foreground colors, not literal text. Never substitute a new mascot.
Fonts: ui-monospace, SFMono-Regular, Menlo, Consolas, monospace throughout. Canvas #111114, terminal #19191d, text #e4e4e7, muted #98989f; terminal art orange ANSI209 #ff875f, purple ANSI141 #af87ff, violet ANSI99 #875fff, shade ANSI238 #444444. Orange measured progress, purple active phase, success #b8bb26, danger #fb4934. Minimal straight rules and spacing measured in character cells. No gradients, glow, illustrations, giant headings, cards or rounded app controls.
One terminal screen, current operation UPDATE 0.4.6 to 0.4.7, native linux-amd64; full existing art once at top, compact operation/version line, completed rows and a single live region, readable recovery/log footer. Motion only a restrained spinner or active marker; no art movement. Exact labels and values survive without color. Honest unknown durations, no simulated progress or fake countdown.
