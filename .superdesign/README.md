# `.superdesign/` — design-tool scratch

This directory holds working output from a design tool. It is scratch: iteration
notes, generated mockups and machine-written JSON that change whenever someone
runs the tool.

**It is not contributor onboarding material, and it is not a source of truth for
the shipped UI.** Nothing here is guaranteed to match what the application
actually renders — read `apps/frontend/src/` for that.

Real design records — the ones with status banners, dated evidence and links to
the commits that closed them — live in [`docs/design/`](../docs/design/). New
contributors should start at [`docs/architecture.md`](../docs/architecture.md)
and `CLAUDE.md`.
