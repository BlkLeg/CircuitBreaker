# npm CLI 08 — Terminal surfaces Implementation Plan

Date: 2026-09-30. Status: **Active — visual scope restored and implementation landed in the working tree 2026-10-02; real-host acceptance gates open.**

**Goal:** Implement the approved gallery using real command data, permanent phase history and
bounded motion, while preserving native streams, JSON and the existing artwork.

**Architecture:** Node and shell renderers consume the same versioned event semantics; one renderer
owns the terminal per operation. Existing native management commands remain the source of truth for
output and accounting.

**Depends on:** 03 event contracts; lifecycle acceptance after 04–07. **Roadmap slice:** 9.
**Requirements:** NPM-03, NPM-06, NPM-09.

## Implementation evidence (2026-10-02)

`packages/cli/src/render.js` prints permanent static phase lines with measured
elapsed duration and Unicode/ASCII completion marks. It emits no ANSI in any
mode, including NO_COLOR. The existing event writer supplies phase timing and the
native decoder validates relayed phases. Lifecycle --json has no cosmetic progress;
--events=jsonl retains its exclusive framed stderr stream. Native management and
uninstall streams are unchanged. Help now describes the shipped scoped commands.
That evidence describes the superseded scope cut; the visual restoration below replaces it.

Existing machine-stream and native forwarding checks remain the acceptance baseline.

## Visual restoration implementation (2026-10-02)

The approved gallery is implemented as terminal output, using existing runtime
evidence and command results. The live Superdesign download draft was checked at
version 2 against the saved export; no new design or paid generation was created.

- Node renderer: permanent measured phase rows, three-line download region in
  wide terminals, compact narrow/short fallback, bounded 8 Hz redraw, resize,
  static/reduced-motion and ASCII modes, cursor restoration and authoritative
  final lifecycle outcomes. Existing `cb_logo` artwork is copied exactly into
  `art.js` and displayed once when an interactive fresh install has room.
- Download callbacks report bytes written, including resumed/restarted transfers;
  machine JSONL retains the existing per-asset measured events and schema.
- Standalone shell UI reports current-phase measurements without inventing an
  overall operation percentage or ETA. Native phase envelopes are relayed when
  a valid operation owns the event descriptor. `--npm-result` gives Node terminal
  ownership, including across sudo's environment reset.
- Grouped npm/native help lists supported commands. Status separates app units
  and shared nginx, reports active-since evidence and explicitly distinguishes
  service state from readiness. Doctor presents the existing JSON verdict with
  real evidence, skipped-check counts and actionable remediation.
- Resources preserves accounting and watch controls, sorts collapsed worker
  totals correctly, separates shared usage, retains missing metrics and limits,
  and wraps narrow layouts using the approved palette.
- Interactive logs format recognized records and native journal JSON without
  dropping multiline, unknown or oversized entries. Redirected logs execute the
  original command directly; lifecycle diagnostics use existing redaction.
- Backup rows time actual adapter boundaries, identify actual artifact size/mode
  and online consistency, and distinguish verified archives from restore rehearsal.
  The existing builder does not expose per-dump/pack events; those preview subrows
  are combined into the honest measured build phase.
- npm removal displays real native/package scopes before typed
  `DELETE circuitbreaker` confirmation. Native uninstall presents the data choice,
  native phase timings, no-color output and a width-gated existing trailing banner.

`cli_terminal_smoke.py` captures read-only event fixtures at wide/narrow/short
sizes, static/no-color/ASCII/dumb modes, resize and SIGTERM. It can import the
packed/installed renderer through `--package`; packed smoke invokes it against
its installed package. These captures are fixture evidence, not host journey
or publication acceptance. Real-host install/update/uninstall, interactive watch
journeys and exact published-package acceptance remain open.

Final working-tree verification: 317 Node tests and 163 focused Python tests
passed. The packed npm smoke passed on Node v24.18.0, verified the installed
shrinkwrap tree (52 packages, no install scripts), and passed all 11 terminal
captures, including wide/narrow resource watch controls. Shell syntax, native
CLI parity, installer inline-library synchronization, Python lint, plan references
and whitespace checks passed. No real host lifecycle or publication was performed.
